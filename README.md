# ASP.NET Document Editor 📝

A Google Docs-inspired collaborative document editor built using ASP.NET Web Forms.

## Features
- Real-time autosave using AJAX
- Multi-user document synchronization (polling)
- Role-based access control (Owner / Editor / Viewer)
- SQL Server integration using ADO.NET
- Fixed race condition in autosave system
- Maintains cursor position during async updates

##  Tech Stack
- ASP.NET Web Forms
- C#
- ADO.NET
- SQL Server
- JavaScript (AJAX, UpdatePanel)
